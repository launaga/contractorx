Ridgeline Builders — Documentation

A static HTML template for general contractors and construction firms: six pages, hand-written SCSS, one vanilla JS file, Bootstrap and GSAP vendored locally. No build step is required to preview it.

Getting started

Unzip the package and open index.html in a browser. Everything is relative-linked, so it works straight off the filesystem or from any static host.

For local development with live reload, serve the folder:

npx http-server . -p 4321 -c-1 -o

Building the CSS

Two stylesheets are produced from the SCSS sources and loaded in order:

sass assets/scss/main.scss        assets/css/style.css      --no-source-map
sass assets/scss/_responsive.scss assets/css/responsive.css --no-source-map

Add --watch while working, and --style=compressed for production. main.scss imports _variables and _components; _responsive.scss imports _variables only and holds every media query, so breakpoint changes never touch component code.

Customising

Start in assets/scss/_variables.scss. Changing these five values rebrands the template:

VariableDefaultUsed for
$brand-700#202a32Headings, links, dark surfaces
$accent-500#e0951cPrimary buttons, underlines, step rules
$font-displayArchivoAll headings
$font-sansInterBody copy and UI
$container1180pxMax content width

Breakpoints ($bp-sm … $bp-xl) live in the same file and drive _responsive.scss.

JavaScript hooks

assets/js/main.js is driven entirely by data attributes. Each feature no-ops if its markup is absent, so you can delete sections freely.

AttributeBehaviour
data-headerAdds .is-stuck once the page scrolls
data-reveal / data-reveal-groupFade-and-rise on scroll, staggered within a group (GSAP when present)
data-count="34"Counts up to the value when scrolled into view (stats band)
data-filters + data-grid + data-tagChip filtering of the service grid
data-accordionScope-of-work accordion
data-contact / data-newsletterClient-side validation and status message

Forms are front-end only. They validate and show a confirmation but send nothing. Point the submit handler at your endpoint in initForms().

Every animation is skipped when the visitor has prefers-reduced-motion: reduce set.
