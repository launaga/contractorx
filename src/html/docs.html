01 Install & preview

Open dist/index.html and you're running.

The dist/ folder is the finished site. Every path in it is relative, so you can double-click dist/index.html and it works from your file system — no server needed.

To work on the source instead, you need Node 18+ once:

Install toolingnpm install
Build everythingnpm run build
Local preview at :4321npm start
Watch SCSS while editingnpm run css:watch

Editing only text and images? Skip Node entirely — edit the files in dist/ directly and upload.

03 Compiling SCSS

One command, one output file.

All 27 SCSS partials compile into a single dist/css/main.css:

npx sass src/scss/main.scss dist/css/main.css --style=compressed --no-source-map

Or run npm run css:watch and leave it running while you edit — every save recompiles in about 200 ms. Bootstrap 5.3's grid and utilities are linked separately as dist/css/bootstrap-grid.min.css; the kit's own layer always loads after it, so your overrides win without !important.

04 Colours & tokens

Rebrand from seven values.

Everything visual routes through src/scss/_variables.scss. Change the seven palette tokens and the whole kit follows — including dark mode, which inverts automatically.

TokenDefaultUsed for
$ink#0A0A0AText, dark surfaces
$paper#FAFAF8Page ground
$panel#F2F2EECards and panels
$rule#111111Strong rules
$rule-soft#D6D5D0Dividers and hairline grids
$mute#6B6B66Captions, secondary text
$reverse-bg / $reverse-fg#111111 / #F6F6F0Reversal blocks — hero, stats, CTA

Adding a brand colour? Set it on $reverse-bg first and check contrast before touching anything else. The design was drawn to hold at 3 reversal blocks per page — more than that and the emphasis stops meaning anything.

05 Fonts

Three roles: display, body, data.

The demo loads Instrument Serif, Inter Tight, and JetBrains Mono from Google Fonts in src/partials/head.html. To self-host — recommended for production — drop the woff2 files into dist/fonts/, replace that <link> with @font-face rules, and preload the two faces used above the fold.

To change a family, edit $font-display, $font-body, or $font-mono in _variables.scss. Keep the roles: a display serif, a humanist sans at 16–18 px, and a mono for labels. Italic is reserved for exactly one highlighted word in the hero.

06 Images & duotone

Swapping in your own photography.

The kit ships vector plates in dist/img/ so it weighs almost nothing out of the box. Replace them with real site photography — same filenames, and nothing else has to change.

For photographs, use a <picture> block so modern formats are served first:

<picture><source srcset="img/hero.avif" type="image/avif"><source srcset="img/hero.webp" type="image/webp"><img src="img/hero.jpg" alt="…" width="2400" height="1350"></picture>

The black-and-white treatment is applied in CSS (filter: grayscale(1) contrast(1.06) on .plate img), so colour photos land in the palette automatically. For a true duotone, export at 100% black on #FAFAF8 in your editor and remove the filter.

Keep width and height on every image — that is what holds CLS under 0.05.

07 Navigation

One file, both menus.

Desktop links and the mobile panel both live in src/partials/nav.html — edit them together so they never drift. The footer's four columns are in src/partials/footer.html.

The current page gets aria-current="page" automatically from the build script's page map (tools/build.mjs); add your new page there when you add a nav link.

08 Adding a page

Copy, retitle, rebuild.

Duplicate any file in src/html/, change the meta block at the top, then run npm run build:

<!--meta { "title": "Careers", "description": "Open roles at RKU." } -->

Those two values feed the <title>, meta description, Open Graph, and Twitter cards. Add the file to sitemap.xml and, if it belongs in the menu, to nav.html.

The six services all render from service-detail.html. For a static site, duplicate it once per service; if you later move to a CMS, the template maps cleanly to one content type.

10 GSAP & motion

Optional, and only in two places.

GSAP is loaded on the home page only, and drives exactly two things: the hero reveal and the stats counter run-up. Delete <script src="js/gsap.min.js"> and both fall back to a CSS transition and a requestAnimationFrame counter — nothing breaks, nothing is missing.

Scroll reveals use IntersectionObserver on any element with class="reveal". Everything respects prefers-reduced-motion: with it on, content appears immediately and counters show their final value.

11 Wiring the forms

Validation ships; the endpoint is yours.

Both forms — general contact and the tender desk — validate in the browser, mark invalid fields, move focus to the first error, and disable the submit button while sending. No data leaves the page.

To connect Formspree, add the action and method, then delete the e.preventDefault() branch at the end of the submit handler in src/js/main.js:

<form class="form-x" action="https://formspree.io/f/YOUR_ID" method="POST" data-validate>

Netlify Forms: add netlify and a hidden form-name field. Your own backend: post the FormData from the handler. The tender form's file input accepts ZIP, PDF, DWG, and XLSX — check your endpoint's upload limit before promising 40 MB.

12 Deploying

Upload dist/. That's the whole deploy.

It's static HTML, so anything works: Netlify, Vercel, Cloudflare Pages, GitHub Pages, or plain shared hosting over FTP. Drag the folder in; there is no build step to configure.

Before you go live: update robots.txt and sitemap.xml with your real domain, replace the ranggakaryautama.example URLs in the canonical and Open Graph tags, and swap the JSON-LD GeneralContractor block for your client's real business details — name, address, phone, and opening hours.
